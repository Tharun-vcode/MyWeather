# MyWeather

🌦️ A Flask-based weather app that integrates OpenWeatherMap APIs to provide real-time weather updates and interactive 5-day forecasts with Chart.js visualizations.

## About The Project

MyWeather is a simple, elegant web application that allows users to get current weather conditions and a 5-day forecast for any city. It demonstrates the integration of a Python backend (Flask) with a public API (OpenWeatherMap) and presents the data in a user-friendly frontend with interactive charts.

### Key Features
*   **Real-Time Weather:** Get current temperature, humidity, wind speed, and conditions for any city.
*   **5-Day Forecast:** View a detailed forecast with temperature trends.
*   **Interactive Charts:** Forecast data is visualized using **Chart.js** for an easy-to-understand graphical representation.
*   **Clean Web Interface:** Built with Flask and HTML templates for a seamless user experience.

## Built With

*   [Flask](https://flask.palletsprojects.com/)
